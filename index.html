Which format should I use?

A quick guide to choosing the right format for your use case.

PNG

Lossless compression. Perfect for images where you need pixel-perfect quality, transparency, or sharp edges.

Lossy compression that produces small files at high quality. The universal format for photographs and general use.

Frequently asked questions

Which image formats are supported?

You can upload PNG, JPEG, WebP, AVIF, GIF and BMP images. Output formats are PNG, JPEG, WebP and AVIF (AVIF support depends on your browser). SVG is not supported for conversion as it requires different rendering.

Are my images uploaded to a server?

No. All processing happens in your browser using the Canvas API and JavaScript. Your images are never sent to any server. Nothing leaves your device.

Does it work on mobile?

Yes. The converter is fully responsive and works on mobile browsers. You can tap to browse your photo library, and everything is touch-friendly. Very large images may take longer on lower-powered devices.

Can I convert multiple images at once?

Yes. Select multiple files using the file browser or drag multiple images at once. The same settings apply to all images. You can download individual files or all converted images as a ZIP.

Can I resize images?

Yes. You can choose from common presets (1920×1080, 1280×720, 1080×1080, 800×600) or enter custom dimensions. Aspect ratio locking is available to keep proportions correct.

Can I reduce image file size?

Yes — in several ways. You can lower the quality slider, switch to a more efficient format like WebP or AVIF, reduce the dimensions, or use the Target File Size feature which automatically adjusts quality to get close to a size you specify.

What happens to transparent images converted to JPEG?

JPEG doesn't support transparency. When you select JPEG as the output format, a background color option appears in Advanced Settings. Transparent areas are filled with that color (white by default) before conversion.

Can I use it offline?

If you've visited the page before, the service worker caches the application files so it may work offline. However, the first load requires an internet connection to load the application.

Is there a file size limit?

The application allows files up to 50 MB. Very large images (50+ megapixels) may be slow or fail on devices with limited memory, as the Canvas API requires holding the entire image in memory.

Why did the converted image become larger?

This can happen when converting to a lossless format like PNG, or when the original was heavily compressed and the output format uses less aggressive compression. Try lowering the quality setting or switching to WebP or AVIF for smaller output.
